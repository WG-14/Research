# Reference audit history

Each subdirectory is an authority-scoped audit session. A session name is
derived from the exact rubric and execution-instruction attachment hashes, and
its iteration budget starts at one. Matrices from different sessions must not
be used as earlier iterations of the current assessment.

`legacy-ce507e16-26871e2d/` preserves the prior session that used rubric
`ce507e16…` and instruction `26871e2d…`. It is historical evidence only.

The current session directory is
`ce507e16b37a8915-a367c42b2d13824e/`. A completed iteration is retained there
as `iteration-NNN-<assessment-surface-sha256>.json` before a later source
surface replaces the canonical generated matrix.
